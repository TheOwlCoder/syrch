Syrch

Syrch is a tag-based user-submitted search engine that aims to make
searching for specific websites for specific tasks 10x easier and reliable.
Each website is user-submitted and reviewed, so no bots or scams cluttering
up the results. But because of this, we need your help.
But because all the websites are user-submitted, there are no
automatically indexing websites.



You can submit websites on the main page.
